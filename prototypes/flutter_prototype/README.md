# スワイプマッチング Flutter 技術検証

Flutterで、用途設定の切替からカード操作、成立、テキスト会話までを共通コードで試すためのソースです。動作データは架空で、アプリを閉じると消えます。相手の意思や承認は検証データで固定しています。

## 起動

Flutter SDKのある環境で、このフォルダーから実行します。AndroidはAndroidツールチェーン、iOSはmacOSとXcodeが必要です。プラットフォームのひな型は既存ソースを保持して生成します。

```text
flutter create --platforms=android,ios,web --project-name swipe_matching_prototype --empty .
flutter pub get
flutter analyze
flutter test
flutter devices
flutter run -d <device-id>
```

ブラウザーで先に確認する場合は `flutter run -d chrome` を実行します。

## 手で確認する操作

1. 「趣味仲間」を選び、「小川 はる」で「興味あり」を押す。成立欄から会話を開き、メッセージを送る。
2. 候補一覧へ戻り、残りの候補を左にスワイプ。候補がなくなり、見送った相手が成立欄に現れないことを確認する。
3. 「仕事相談」を選び、最初の案件を右にスワイプする。承認済みの案件が成立し、趣味仲間の会話が表示されないことを確認する。
4. 2件目へ応募する。未承認の案件は成立欄に出ないことを確認する。
5. 「趣味仲間」に戻る。アプリを開いている間、さきほどの会話が保持されることを確認する。
